# Mobile API

Базовый JSON API для кроссплатформенного приложения портала.

Все адреса начинаются с `/mobile/api`.

## Авторизация

`POST /mobile/api/auth/login`

```json
{
  "username": "user",
  "password": "password"
}
```

Возвращает текущего пользователя и устанавливает обычную сессию портала.

`POST /mobile/api/auth/logout`

Завершает сессию.

`GET /mobile/api/me`

Возвращает профиль пользователя и основные разрешения для мобильного интерфейса.

## Уведомления

`GET /mobile/api/notifications?limit=30`

Возвращает последние уведомления по задачам и инцидентам, а также общее число непрочитанных.

`POST /mobile/api/notifications/incident/<notification_id>/read`

Помечает уведомление по инциденту прочитанным.

## Справочники для инцидентов

`GET /mobile/api/incidents/meta`

Возвращает категории инцидентов и доступные параллели.

`GET /mobile/api/classes?grade=5`

Возвращает классы текущего учебного года. Параметр `grade` необязательный.

`GET /mobile/api/classes/<class_id>/children`

Возвращает учеников выбранного класса.

## Инциденты

`GET /mobile/api/incidents/mine?limit=50`

Возвращает две подборки: созданные пользователем инциденты и назначенные ему инциденты.

`POST /mobile/api/incidents`

```json
{
  "occurred_at": "2026-06-09T14:30:00+03:00",
  "category": "Нарушение дисциплины",
  "description": "Описание ситуации",
  "initial_work": "Что уже сделано",
  "child_ids": [123, 456]
}
```

Можно вместо `occurred_at` передать пару:

```json
{
  "occurred_date": "2026-06-09",
  "occurred_time": "14:30"
}
```

Проверки совпадают с веб-формой: обязательна категория, описание, хотя бы один ученик; дата не старше 48 часов и не в будущем.
