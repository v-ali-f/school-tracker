# Уведомления по задачам в MAX-бот

Добавлен дополнительный канал уведомлений по задачам в существующий MAX-бот инцидентов.

## Как работает

- Внутренние уведомления по задачам остаются без изменений.
- Email-уведомления остаются без изменений.
- Если пользователь привязал MAX-бот через профиль, портал дополнительно отправляет ему сообщение через `POST /api/notify` бота.
- Используются существующие переменные окружения портала:
  - `BOT_API_URL`
  - `BOT_SHARED_SECRET`

## Что отправляется в MAX

- новая задача;
- изменение срока;
- комментарий;
- отправка на проверку;
- возврат на доработку;
- закрытие;
- просрочка;
- системная автозадача;
- другие события задач, которые уже проходят через `_deliver_notifications`.

## Безопасность

Если задача помечена приватной или похожа на СППС/сопровождение, в MAX не раскрываются подробности задачи — пользователь получает безопасное уведомление и ссылку на портал.

## Важно

Бот уже имел endpoint `/api/notify`, поэтому сам MAX-бот менять не требуется. В этой версии изменён портал: добавлен метод `BotClient.notify()` и отправка MAX-уведомления из `app/tasks.py`.
