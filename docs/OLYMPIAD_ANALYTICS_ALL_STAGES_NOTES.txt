Изменения версии: аналитика олимпиад ВСОШ

1. На странице /olympiads/analytics добавлен новый вид: все этапы ВСОШ отображаются на одной странице.
2. Круговые диаграммы сохранены, но теперь они компактные: школьный, муниципальный, региональный и заключительный этапы выводятся отдельными карточками.
3. В каждой карточке показываются: всего, победители, призёры, участники, аннулированные результаты.
4. Добавлена общая сравнительная диаграмма этапов.
5. Таблица сводки по этапам стала компактнее.
6. Исправлена runtime-миграция поля olympiad_result.is_annulled для старых баз: колонка добавляется с DEFAULT FALSE и NOT NULL без ошибки на существующих строках.

Допобразование/ШСК по-прежнему удалены из этой сборки.
