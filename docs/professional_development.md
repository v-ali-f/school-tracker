# Повышение квалификации в «Альтаире»

Раздел `/professional-development/` показывает историю курсов, охват сотрудников и планирование по трехлетнему периоду. Личная история доступна каждому пользователю по адресу `/professional-development/my`. Руководители и методисты видят общую аналитику, загружают таблицы и проверяют нераспознанные ФИО. В разделе кафедр отображаются курсы и статусы преподавателей кафедры.

## Загрузка

Файл `.xlsx` должен называться с учебным годом (`2025-2026.xlsx`) и содержать столбцы `ФИО`, `Должность`, `Наименование курса`, `Организация`. Можно загрузить несколько файлов сразу. Повторная загрузка года обновляет записи без дублей; исчезнувшие из файла записи архивируются. Система связывает записи с учетной записью только при единственном совпадении полного ФИО. Остальные доступны на странице «Проверить привязку». Сами исходные таблицы в репозиторий не добавляются.

Для первоначальной загрузки на сервере после миграции можно использовать `python scripts/import_professional_development.py <файлы.xlsx...>`.

## Значение показателей

Педагогические сотрудники определяются по действующей нагрузке и составу кафедр, роли в «Альтаире» и педагогической должности в загруженных записях. Общий процент обучавшихся считается от действующих учетных записей сотрудников с ФИО. Трехлетний показатель считается только для педагогических сотрудников. Если известна точная дата ручной записи, следующий ориентир рассчитывается через три календарных года; для импортированных записей без даты используется учебный год + 3. Год без даты не превращается в фиктивную дату.

Статья 47 Федерального закона № 273-ФЗ закрепляет право педагогического работника на дополнительное профессиональное образование по профилю педагогической деятельности не реже одного раза в три года. Дашборд помогает планировать обучение и не устанавливает факт нарушения закона. Исходные файлы не содержат дат, часов, номеров удостоверений или подтверждения вида программы; для юридически точного учета эти сведения необходимо дополнить.
