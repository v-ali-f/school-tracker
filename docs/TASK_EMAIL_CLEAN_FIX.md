# Исправление email-уведомлений по задачам

Что исправлено:

1. В модель пользователя добавлены поля, которые уже использует `app/tasks.py`:
   - `task_notifications_enabled`
   - `task_email_enabled`
   - `task_notify_only_important`

2. В `app/bootstrap.py` добавлено автоматическое создание этих колонок в старой базе PostgreSQL при запуске проекта.

3. Страница администратора `/admin/email` теперь синхронизирует SMTP-настройки не только со служебной таблицей `system_email_settings`, но и с основной моделью `SystemMailSettings` / таблицей `system_mail_settings`, которую использует сервис отправки писем задач.

4. Исправлена запись boolean-полей PostgreSQL: вместо `1/0` используются `True/False`.

5. Сервис почтовых настроек игнорирует пустые активные SMTP-записи и не блокирует fallback-настройки.

После обновления с GitHub достаточно перезапустить сервис. `ensure_runtime_schema()` добавит недостающие колонки автоматически.
