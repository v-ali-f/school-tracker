# Единая дизайн-система портала «Альтаир»

Дизайн-система применяется ко всем новым страницам и к разделам, которые переводятся на единый интерфейс.

## Структура

- `workspace_ui.css` — стабильная точка подключения дизайн-системы.
- `workspace_tokens.css` — цвета, интервалы, радиусы, тени и размеры элементов.
- `workspace_shell.css` — боковая навигация, верхняя панель и адаптивный каркас.
- `workspace_components.css` — заголовки, кнопки, формы, таблицы, статусы, показатели, уведомления и пустые состояния.
- `components/workspace_ui.html` — Jinja-компоненты для повторного использования в шаблонах.
- `hub_workspace.css` — компактная сетка тематических разделов и карточек переходов.
- `school_plan_workspace.css` и остальные файлы модулей — только особенности конкретного раздела.

Базовая дизайн-система не должна импортировать стили прикладного модуля.

## Создание страницы

Страница должна наследовать `workspace_layout.html`:

```jinja
{% extends "workspace_layout.html" %}
{% from "components/workspace_ui.html" import page_header, status_badge, empty_state %}

{% block workspace_content %}
  {{ page_header('Название', 'Краткое описание страницы') }}
{% endblock %}
```

Дополнительный CSS подключается через `workspace_head_extra` и содержит только стили модуля.

## Общие компоненты

- `page_header` — заголовок, описание, возврат и действия страницы.
- `metric` — показатель со стандартным цветовым состоянием.
- `status_badge` — компактный статус `info`, `success`, `warning` или `danger`.
- `filter_panel` — панель фильтров.
- `card` — стандартная карточка раздела.
- `empty_state` — сообщение об отсутствии данных.

В CSS также доступны классы `ws-table-wrap`, `ws-tabs`, `ws-notice`, `ws-action-bar`, `ws-filter-grid` и `ws-component-grid`.

## Правила

1. Использовать переменные `--ws-*`, не добавлять новые базовые цвета и размеры внутри модуля.
2. Не копировать стили бокового меню, верхней панели, кнопок, полей и таблиц.
3. Использовать четыре смысловых состояния: информационное, успешное, предупреждение и ошибка.
4. Проверять страницу на ширине 390 и 1440 пикселей.
5. Не допускать горизонтального переполнения всей страницы.
6. Проверять права всех ролей, которым доступен раздел.
7. Добавлять тест маршрута и основных элементов интерфейса.

## Эталонная страница

Администратор и директор могут открыть `/design-system/`. Страница показывает актуальные кнопки, статусы, показатели, фильтры, уведомления и пустое состояние.
