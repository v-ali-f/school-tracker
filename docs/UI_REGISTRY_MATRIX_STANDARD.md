# Стандарт табличных реестров

Для списков и реестров используется компактный матричный вид, аналогичный
таблице на странице «Сводный контингент»:

- видимые тонкие границы всех ячеек;
- высота обычной строки около 25 пикселей;
- небольшие внутренние отступы;
- спокойная заливка заголовка и чередование строк;
- числовые и короткие значения выравниваются по центру;
- действия в строке отображаются компактными кнопками-иконками;
- широкая таблица прокручивается по горизонтали без увеличения высоты строк.

Общие классы находятся в `app/static/css/registry_matrix.css`:

- `registry-filter-panel` — компактная панель фильтров;
- `registry-matrix-card` — контейнер таблицы;
- `registry-matrix` — таблица-матрица;
- `registry-cell-center` — центрирование короткого значения;
- `registry-row-actions` и `registry-row-action` — действия строки;
- `registry-empty-row` — пустое состояние реестра.

Новые реестры и перерабатываемые списки должны использовать эти классы, если
для конкретной страницы не требуется иной специализированный вид.
