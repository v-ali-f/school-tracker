# Этап 4. Снимки контингента и учебные группы

## Результат этапа

Реализована единая модель учебных объединений, на основании которых на
следующем этапе будет распределяться педагогическая нагрузка:

- полный класс;
- подгруппа одного класса;
- метагруппа из нескольких классов;
- группа внеурочной деятельности;
- группа дополнительного образования;
- индивидуальная группа.

Группа всегда связана с конкретной строкой плана, дисциплиной, корневой
версией тарификации и снимком контингента. Действующая Excel-тарификация
кафедр не изменена и остаётся основным источником до отдельного этапа
переключения.

## Учебные недели и годовой объём

В строку учебного плана добавлено поле `weeks_count`. Пользователь может
указать недельную нагрузку и количество учебных недель, после чего годовой
объём рассчитывается сервером:

```text
годовые часы = часы в неделю × количество учебных недель
```

Например, `5 часов × 34 недели = 170 часов`. Результат сохраняется в
`annual_hours`, поэтому его можно использовать в отчётах и дальнейших
расчётах. Для нестандартной реализации разрешено указать только годовой
объём. Количество недель без недельных часов не принимается.

## Снимок контингента

Перед созданием групп формируется снимок классов и активных зачислений для
конкретной корневой версии. Он сохраняет:

- исходный класс, параллель и здание;
- численность класса;
- поимённый состав;
- исходные идентификаторы класса, ребёнка и зачисления;
- дату, номер редакции и контрольную сумму.

Обновление реестра контингента не меняет ранее созданный снимок. Новый снимок
получает следующую редакцию, а предыдущий остаётся в истории.

## Правила групп

- тип группы должен соответствовать виду исходного плана;
- полный класс, подгруппа и индивидуальная группа используют один класс;
- метагруппа использует не менее двух классов;
- поимённая группа хранит участников из выбранных исходных классов;
- группа полного класса автоматически получает весь состав класса;
- режим `COUNT_ONLY` хранит численность без списка участников;
- один ученик не может одновременно входить в пересекающиеся группы одной
  строки плана;
- периоды группы и участников проверяются по учебному году;
- готовая группа доступна только для чтения;
- закрытие фиксирует дату и основание и завершает периоды участников;
- изменение защищено номером ревизии от параллельной перезаписи.

Для подгрупп отображается покрытие класса: ожидаемая численность,
распределённые ученики, остаток и дубли.

## Интерфейс

Добавлены:

- `/workload/groups/` — реестр групп и управление снимком;
- `/workload/groups/new` — создание группы;
- `/workload/groups/<id>` — карточка, состав, покрытие и история;
- `/workload/groups/<id>/edit` — изменение черновой группы.

Форма использует строки действующих планов и показывает только классы и
обучающихся выбранного снимка.

## Границы этапа

На этом этапе ещё не реализованы:

- назначение педагогов и распределение плановых часов;
- вакансии и нераспределённые остатки нагрузки;
- доля ставки и расчёт оплаты;
- массовое копирование групп между версиями;
- переключение кафедр с Excel на новый источник.
