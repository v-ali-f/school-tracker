# Этап 1: паспорта кабинетов

## Что реализовано

- Один паспорт на постоянный ID кабинета. При смене закреплённого педагога редакции и проверки остаются на месте.
- Тип, этаж и площадь вводятся в основном реестре кабинетов и в паспорте доступны только для чтения.
- Назначенные педагоги сохраняют новые редакции общего паспорта. Номер исходной редакции защищает от перезаписи параллельных изменений.
- Ответственный за ОТ назначается директором на период. Только действующий ответственный может проверять паспорт; повторная отметка сохраняет прежнюю запись.
- Реестр с фильтрами по зданию и статусу, базовыми счётчиками, печатным просмотром и вложениями.
- Время событий хранится в UTC, в интерфейсе отображается по `SCHOOL_TIMEZONE` (по умолчанию `Europe/Moscow`).

## Установка в тестовой среде

1. Сделать резервную копию базы и каталога загрузок.
2. Применить миграцию `b7f2c9d4a601` через штатную команду `flask db upgrade` **до запуска новой версии приложения**. Обычный `db.create_all()` не добавит новые колонки к существующей таблице кабинетов.
3. Проверить переменную `UPLOAD_FOLDER`; вложения паспортов будут сохраняться в её подкаталоге `safety_passports`.
4. В основном реестре заполнить тип, этаж и площадь кабинетов. Для кабинетов начальных классов тип должен содержать «начальн».
5. Назначить ответственного за ОТ от имени директора и пройти пилот на одном здании.

## Границы пилота

Печатный просмотр содержит структурированные данные паспорта. Статические тексты и окончательное оформление формы паспорта начальных классов следует включить после подтверждения актуальности школьного образца ответственным за ОТ: предоставленный образец содержит старые нормативные формулировки. До этого печатный просмотр служит для согласования макета.

Миграция создаёт пустые паспорта для кабинетов с уже назначенными педагогами. Для новых кабинетов паспорт создаётся при назначении. Кабинеты без ответственного отображаются в общем реестре со статусом «Не начат».

## Приёмка

- Передать кабинет от одного педагога другому: ID паспорта, редакции и проверки должны сохраниться.
- Проверить паспорт, затем изменить его: должна появиться новая редакция со статусом повторной проверки.
- Открыть один паспорт двум педагогам: второй ввод с устаревшим номером редакции должен получить сообщение о конфликте.
- Убедиться, что учитель без назначения и директор без полномочий проверяющего не могут изменить результат проверки.
- Проверить доступ к вложению от назначенного и постороннего пользователя.
