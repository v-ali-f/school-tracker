# Качество образования: ОГЭ и ЕГЭ

Раздел `/quality/` доступен в меню «Разделы и сервисы» пользователям с правом `quality_view` (администратор, директор, заместитель директора, методист). Загрузка доступна по `quality_import` (администратор, директор, заместитель директора). API также проверяет эти права.

## Обновление

1. В МЭШ открыть «Журналы классов, групп» и нажать «Выгрузить все журналы». В разделе Альтаира «Обновление данных» загрузить ZIP.
2. В таблице «ГИА 2026–2027» выбрать «Файл → Скачать → Microsoft Excel (.xlsx)» и загрузить всю книгу, включая листы 9-х и 11-х классов.
3. Проверить «Контроль сопоставления»: ученики связываются между источниками по классу и полному ФИО. Несовпадения не исправляются автоматически.

Перед публикацией раздела выполнить `flask db upgrade`: на рабочем сервере `AUTO_SCHEMA_BOOTSTRAP=0`, поэтому таблица создаётся миграцией `6a3f9c1d5e20`.

Каждая загрузка сохраняется отдельным снимком в `quality_snapshot`, привязанным к текущему учебному году. Раздел показывает последний снимок каждого типа. Повтор того же файла не создаёт новый снимок; более старая выгрузка журнала не заменяет свежую.

Рекомендуемый рабочий ритм — раз в месяц, а ближе к ГИА по необходимости. Автоматическая выгрузка из МЭШ здесь не используется: пока подтверждена только штатная кнопка ZIP. Для прямого подключения нужен официальный согласованный способ доступа. Прямая синхронизация с Google Таблицами потребует авторизации сервисного доступа; текущий источник — экспорт XLSX.

## Расчёты

- Средний балл — среднее текущих отметок 2–5 за выбранный период по предметам, выбранным для ГИА. Для математики объединяются алгебра, геометрия и вероятность и статистика.
- Пропуски — количество явных отметок «н» или «нб» в этих журналах. Процент посещаемости не вычисляется: выгрузка не даёт надёжного знаменателя по проведённым урокам.
- «Сигналы внимания» возникают при среднем ниже 3,5 (при трёх и более отметках), двух и более оценках «2», отсутствии текущих отметок по выбранному экзамену, неполном выборе ОГЭ или отсутствии ученика в одном из источников. Это рабочие подсказки, а не решение о допуске к ГИА.
- Заголовки листов ГИА содержат имена педагогов; в разделе они приводятся к названию предмета. Выбор отмечается значением `1`, а уровень математики ЕГЭ — значением `база`, `проф` или `профиль`.

Интерфейс не содержит данных учеников в коде или статических файлах. Сведения поступают из двух загруженных источников и доступны только после входа и проверки роли.
