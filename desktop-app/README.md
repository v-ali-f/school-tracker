# Настольное приложение портала

Это Electron-оболочка для школьного портала сопровождения обучающихся.

## Что делает

Приложение открывает портал:

http://10.172.85.55/

в отдельном окне без необходимости вводить адрес в браузере.

## Сборка на Windows

1. Установить Node.js LTS.
2. Открыть PowerShell в папке desktop-app.
3. Выполнить:

npm install

4. Для запуска без сборки:

npm start

5. Для сборки portable .exe:

npm run build:win

Готовый файл появится в папке:

dist/Система сопровождения обучающихся.exe

## Настройка адреса портала

Адрес портала находится в файле:

config.json

Если сервер изменится, можно поменять portalUrl.
