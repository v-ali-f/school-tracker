# Настольное приложение портала

Это Electron-приложение для школьного портала сопровождения обучающихся.

## Что делает

Приложение подключается к мобильному API портала:

http://10.172.85.55/mobile/api

и дает базовые рабочие экраны:

- вход в систему;
- просмотр пользователя и прав;
- просмотр уведомлений;
- просмотр последних инцидентов;
- добавление нового инцидента с выбором класса и учеников.

Кнопка "Открыть портал" открывает полную веб-версию:

http://10.172.85.55/

## Сборка на Windows

1. Установить Node.js LTS.
2. Открыть PowerShell в папке desktop-app.
3. Выполнить:

npm install

4. Для запуска без сборки:

npm start

5. Для сборки portable .exe:

npm run build:win

Готовый файл появится в папке:

dist/Система сопровождения обучающихся.exe

## Настройка адреса портала

Адрес портала и API находится в файле:

config.json

Если сервер изменится, можно поменять `portalUrl` и `apiBaseUrl`.
