# Мобильное приложение

Flutter-приложение для Android и iPhone поверх существующего API портала.

## Что уже подключено

- вход через `/mobile/api/auth/login`;
- профиль через `/mobile/api/me`;
- уведомления через `/mobile/api/notifications`;
- мои инциденты через `/mobile/api/incidents/mine`;
- создание инцидента через `/mobile/api/incidents`;
- выбор класса и учеников через `/mobile/api/classes`.
- главный экран с карточками разделов по ТЗ;
- нижнее меню: Главная, Уведомления, Задачи, Документы, Профиль;
- подготовленные экраны задач, документов, обращений, плана работы и поиска.

## Первый запуск

На обычном терминале Mac, где Flutter может обновлять свой кэш:

```bash
cd "/Users/aleksandr/Documents/Школьный портал/school-tracker/mobile-app"
flutter create --platforms=android,ios --org ru.school1324 .
flutter pub get
flutter run
```

На экране входа можно выбрать и сохранить сервер:

```text
Локальный компьютер: http://127.0.0.1:5001/mobile/api
Сервер школы: http://10.172.85.55/mobile/api
Другой адрес: для физического iPhone или другого сервера
```

Выбранный адрес сохраняется в настройках приложения. При следующем запуске
выбирать его повторно не нужно.
