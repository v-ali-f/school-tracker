# Установка school-tracker — инструкция

Система работает локально на вашем компьютере. База данных создаётся автоматически при первом запуске.

---

## Требования

- **Python 3.10 или новее** — скачать с https://python.org/downloads/
  - При установке на Windows обязательно поставьте галку **"Add Python to PATH"**
- **pip** — входит в стандартную поставку Python

---

## Шаг 1. Распакуйте папку

Положите папку `school_tracker_copy` куда удобно, например:
- Windows: `C:\school_tracker\`
- Mac: `~/school_tracker/`

---

## Шаг 2. Откройте терминал в папке системы

**Windows:**
- Откройте папку в Проводнике
- В адресной строке введите `cmd` и нажмите Enter

**Mac:**
- Откройте Terminal
- Введите `cd ~/school_tracker` (или перетащите папку в терминал после `cd `)

---

## Шаг 3. Создайте виртуальное окружение

```bash
python -m venv .venv
```

Активируйте:

```bash
# Mac / Linux:
source .venv/bin/activate

# Windows:
.venv\Scripts\activate
```

После активации в начале строки появится `(.venv)`.

---

## Шаг 4. Установите зависимости

```bash
pip install -r requirements.txt
```

Установка занимает 1–3 минуты. Интернет нужен только на этом шаге.

---

## Шаг 5. Инициализируйте базу данных

```bash
flask --app run init-db
flask --app run repair-runtime-columns
flask --app run seed-academic-year
flask --app run seed-olympiads
```

Эти команды создают структуру базы данных и заполняют справочники.

---

## Шаг 6. Создайте администратора

```bash
python init_admin.py
```

Создаётся пользователь `admin` с паролем `admin123`. **Смените пароль после первого входа.**

---

## Шаг 7. Запустите систему

```bash
python run.py
```

Откройте браузер и перейдите по адресу: **http://localhost:5001**

---

## Настройка под свою школу

После входа под `admin` перейдите в **Настройки → Организация** и укажите:
- Название школы

## Важные замечания

### PDF-отчёты

Генерация PDF требует библиотеки **WeasyPrint**. Если PDF не нужны — всё остальное работает без неё.

**Windows:** WeasyPrint работает только с установленным GTK.
Инструкция: https://doc.courtbouillon.org/weasyprint/stable/first_steps.html#windows

**Mac:** установите зависимости через Homebrew:
```bash
brew install pango cairo libffi
```
Если Homebrew не установлен: https://brew.sh

### База данных
По умолчанию используется SQLite — файл `app.db` создаётся в папке системы автоматически. Никаких дополнительных серверов баз данных не нужно.

Для продакшн-развёртывания можно переключиться на PostgreSQL — см. `README.md`.

### Папка uploads/
Здесь хранятся загруженные через систему документы. Папка создана и пустая — это нормально.

## Если что-то пошло не так

**`python: command not found`** → На Mac попробуйте `python3` вместо `python` (например: `python3 -m venv .venv`, `python3 init_admin.py`). На Windows — Python не установлен или не добавлен в PATH, переустановите с галкой "Add to PATH".

**`ModuleNotFoundError`** → виртуальное окружение не активировано. Повторите шаг активации из Шага 3.

**Страница не открывается** → убедитесь, что `python run.py` запущен и в терминале нет ошибок. Адрес — http://localhost:5001, не 5000.

**`AcademicYear` ошибка на дашборде** → выполните `flask --app run seed-academic-year`.
