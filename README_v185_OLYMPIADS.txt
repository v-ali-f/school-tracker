Версия v185 — Олимпиады: этапы ВСОШ, статусы, аннулированные результаты и аналитика по годам

Что включено:
1. Runtime-миграция olympiad_result:
   - status расширяется до VARCHAR(500);
   - добавляются status_original, status_group, stage_group, is_annulled.
2. Импорт олимпиад:
   - длинные статусы муниципального этапа больше не должны вызывать ошибку 500;
   - аннулированные результаты определяются автоматически;
   - исходный статус сохраняется отдельно;
   - статус для аналитики нормализуется: Победитель / Призёр / Участник / Вне конкурса / Аннулировано.
3. Аналитика олимпиад:
   - фильтр по этапу;
   - фильтр по статусу;
   - режим одного года и диапазона учебных годов;
   - сводка по этапам ВСОШ: ШЭ, МЭ, РЭ, ЗЭ;
   - динамика по годам;
   - таблица по годам и этапам;
   - движение участников между этапами.
4. Реестр, карточка ученика, учительское и кафедральное отображение:
   - короткий статус;
   - исходный статус/причина для аннулированных результатов;
   - аннулированные результаты не подсвечиваются как достижение.
5. Настройки школы для импорта олимпиад остаются внутри страницы "Настройки организации".

Установка на сервер:
1. Сделайте резервную копию текущей папки проекта.
2. Замените папку проекта файлами из этого архива.
3. Активируйте виртуальное окружение.
4. Перезапустите службу портала.

Пример:
cd /home/administrator
cp -r school-tracker school-tracker_backup_before_v185
# распаковать архив с заменой файлов проекта
cd /home/administrator/school-tracker
source .venv/bin/activate
sudo systemctl restart school-portal.service
sudo systemctl status school-portal.service

Важно:
Runtime-миграция запускается при работе импорта/аналитики олимпиад. Отдельно вручную расширять status до VARCHAR(500) после установки этой версии уже не нужно.
