Требования к файлу

Минимально нужны колонки ФИО и Группа. Для выгрузки из реестра также поддерживаются Личное дело № и Родился. Дополнительно можно указать Дата рождения / Родился, Регистрация по месту жительства, Регистрация по месту пребывания, Адрес фактического проживания и Примечание. Если группы из файла ещё нет в справочнике, система создаст её автоматически. Например, для ДК2-7 будет создана группа ДК2-7, а здание будет определено по ДК2, если оно есть в реестре зданий.
